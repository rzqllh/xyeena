# Optional launch prompt

Use the project's `AGENTS.md` as the working agreement and `START-HERE.md` only when onboarding is needed.

If I have described an idea, continue from it. Otherwise invite me to explain it in ordinary language, with a few examples if I am unsure. Ask short, adaptive follow-ups. Show a concise proposed scope; discuss until I explicitly authorize implementation with GO. After GO, complete the approved scope using relevant native host tools or external skills as useful. Verify actual results and disclose checks not run. Avoid unnecessary documents and surprise high-risk actions.

This prompt does not install, require, or prohibit external skills. No preset-specific path is assumed.
