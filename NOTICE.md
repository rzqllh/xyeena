# Notices and research influences

Xyeena is an original implementation. It does not vendor or require the projects below at runtime.
The project was informed by public patterns from the Agent Skills ecosystem, including:

- obra/superpowers — composable engineering workflows, evidence-before-completion,
  subagent isolation, persistent execution ledgers, bounded review loops.
- mattpocock/skills — small composable skills, grilling/frontier questioning,
  domain language, code review separation, progressive disclosure.
- miqdadbadjuber/anti-slop — treating anti-generic output as a filter rather than
  a prescribed style, purpose-driven UI decisions, delivery-time quality checks.
- pbakaus/impeccable and related design-skill ecosystems — shape/build/critique/audit
  separation and production UI craft across typography, layout, interaction and hardening.
- Agent Skills specification — portable SKILL.md packaging and progressive disclosure.
- A2A / modern agent SDK patterns — task/artifact separation and stateful orchestration concepts.

No substantial third-party text is copied into Xyeena. Any future vendored code must retain
its upstream license and attribution separately.
