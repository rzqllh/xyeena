# Adapter Registry

Adapters are composable and optional.

Current starter adapters:

- `generic-git.json`
- `node.json`
- `nextjs.json`
- `python.json`
- `static-web.json`
- `docs-only.json`
- `monorepo.json`
- `vercel.json`
- `github.json`

Adapters describe:
- detection signals
- risk path hints
- verification command candidates
- special warnings
- optional harness activation hints

Adapters never replace project profiles.
