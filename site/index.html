Skills vs Harness

Two selectable components in one npm package. Host authorization and optional project Harness are separate decisions.

Component 1

Agent Skills

19 portable capabilities

Behavioral capabilities for planning, implementation, review, debugging, security, UI craft, and orchestration.

  • Target paths: .agents/skills/ or .claude/skills/
  • Activation: Keyword and context resolver
  • Execution: Progressive disclosure via SKILL.md
  • Dependencies: Mandatory prerequisites declared in capability contracts
Component 2

Project Harness

41 guardrail docs in 11 groups

Project-level guardrails, risk classification, invariant scans, and native verification enforcement.

  • Target paths: .xyeena/harness/guides/ and .xyeena/profile.md
  • Groups: Core, Profile, Product, Design, Engineering, Quality, Security, Performance, Ops, Hygiene, Safety
  • Verification: Runs real project scripts without false PASS claims
  • Bootstrap mode: Diagnostics run before project configuration is saved
Explicit selection: Passing all selects every item only when explicitly specified. The installer never defaults to full installation.

Installer Safeguards

Built for cautious integration into existing repositories.

01

No Silent Install

Installation requires explicit scope, runtime and preset selection. Review planned changes before confirming.

02

Dependency Preview

Mandatory skill dependencies are computed and reported before any file is written to disk.

03

No Overwrites Without Consent

Unknown and modified files are preserved by default. Managed updates require review, ownership checks and explicit consent.

04

Cancel Equals Zero Writes

Canceling at any confirmation step exits immediately with zero filesystem modifications.

05

Root Integrity

Does not silently rewrite root AGENTS.md or install Git hooks without explicit confirmation.

Command Reference

The published CLI includes installation and diagnostics. Some orchestration and compact-layout commands are available in current source but not yet in the published npm version.

Repository-recorded npm baseline: 0.4.1 (check registry before release). CLI-specific native consent/deny accepted on Windows; IDE interception, other runtimes and Simpul remain gated. Source-only features are not npm-published.

Command Type Description
init Interactive Select global or workspace skill installation, runtimes and optional project Harness.
doctor Read-only Check existing Agent Skills installation and runtime paths.
harness doctor Read-only Inspect project Harness configuration and Git status.
audit Read-only Run read-only inspection against active project adapters.
scan Read-only Scan repository invariants; exits with code 1 on blockers.
risk Read-only Classify risk level of changed files against base branch.
verify Execution Executes native project checks. Returns INCOMPLETE if no meaningful check ran.
run-init --goal TEXT State Initialize append-only run journal and task ledger in .xyeena/runs/.
list Read-only List all packaged skills, classes, and categories.
check Read-only Validate capability JSON schemas and runtime manifests.
eval Read-only Run deterministic evaluation suites for routing and governor.
ops preflight Read-only (source) Redacted host executable and hook prerequisites; does not invoke AI or attest native enforcement.
version Read-only Print current CLI and package version.
