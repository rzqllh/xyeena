# Research — v1 Procedure Entry

**Activate when:** The task needs current API behavior, version-matched docs, normative standards, benchmark baselines or upstream source inspection.

**Do not activate for:** The complete correct source is already provided or a pure transformation needs no external claims.

## Execution route

1. Form falsifiable research questions and rank by decision impact; limit scope and define source freshness requirements.
2. Gather canonical primary documentation and inspected code on pinned SHA/version; distinguish README claims from implementation and tests.
3. Audit source licenses and file-specific conditions before copying any code, text, images or data.
4. Triangulate conflicts using exact text/code and reproduction where practical; never turn absence of contrary data into proof.
5. Produce a decision-ready evidence matrix with fact, source, observed version/date, confidence, unknowns, implications and follow-up.

**Output contract:** Source ledger, narrowed findings, unresolved contradictions, recommended next discriminating test.

**Failure boundary:** When source access is blocked, explicitly mark the claim UNKNOWN; never invent an upstream feature or license.
